# Project Specification

## 1. Vision & Goals

The goal of this project is to serve as a reliable, well-documented starting point for new applications and tools.

- **Modularity**: Components and modules should remain decoupled and easy to extend.
- **Maintainability**: Clear documentation, clean code style, and transparent task tracking.
- **Agent-Ready**: Preconfigured with explicit agent instructions in `AGENTS.md` for seamless pair programming.

## 2. Architecture & Design Principles

- **Separation of Concerns**: Keep business logic, data persistence, and interface/presentation layers distinct.
- **Simplicity First**: Favor minimal and standard libraries before adopting heavy third-party dependencies.
- **Traceability**: All non-trivial changes should map to an item in [`TASKS.md`](TASKS.md).
