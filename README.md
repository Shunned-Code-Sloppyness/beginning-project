# Beginning Project

A clean foundation repository for starting new software projects, experiments, and agent-assisted workflows.

## Overview

This repository is designed to provide a structured starting point for development, documentation, and task tracking.

## Repository Structure

| File | Description |
|------|-------------|
| [`README.md`](README.md) | Project overview and quickstart guide |
| [`PROJECT.md`](PROJECT.md) | High-level project specifications, goals, and architecture |
| [`AGENTS.md`](AGENTS.md) | Instructions, rules, and constraints for AI coding agents |
| [`TASKS.md`](TASKS.md) | Task list, roadmap, and milestone tracking |

## Getting Started

1. **Clone the repository**:
   ```bash
   git clone git@github.com:Shunned-Code-Sloppyness/beginning-project.git
   cd beginning-project
   ```

2. **Define project scope**:
   - Update [`PROJECT.md`](PROJECT.md) with specific project goals and technical stack.
   - Track planned features in [`TASKS.md`](TASKS.md).
